## ✨ 当前版本

当前线上版本是 **剧情先行版**：先完整呈现《科王象棋》的主线故事，让玩家可以从“八冠王”一路推进到“巅峰对决”与尾声。

| 内容 | 说明 |
| --- | --- |
| 主角 | 科王，象棋界年少成名的八冠王 |
| 对手 | 横空出世的 AI，靠计算、训练和快速学习压过旧棋盘 |
| 主线 | 人机大战惨败 → 道心破碎 → 棋魂觉醒 → 创造新规则 → 三局两胜终局 |
| 玩法状态 | 棋局事件暂以剧情结算呈现，后续会逐个替换为真实对局 |
| 进度 | 浏览器本地保存，可回看已读剧情 |

## 📖 剧情结构

| 篇章 | 核心事件 |
| --- | --- |
| 序章 | 科王少年封王，八冠加身，成为旧棋盘里最耀眼的人 |
| 第一幕 | AI 横空出世，人类棋手接连倒下 |
| 第二幕 | 科王承载人类希望出战十番棋，却被彻底击碎 |
| 第三幕 | 他怀疑的不只是自己，而是整套旧规则 |
| 第四幕 | 雨夜重开棋盒，车魂初醒 |
| 第五幕 | 车、马、炮、兵、仕、相依次觉醒，每一枚棋子都打开一种新规则 |
| 第六幕 | 王魂与组合技出现，科王不再只是解锁能力，而是在创造一套棋 |
| 终幕 | 三局两胜：先痛快复仇，再被 AI 偷学，最后在双方全觉醒中完成巅峰对决 |

## 🧠 AI 与棋魂设定

故事里的 AI 不是传统反派，而是旧规则里最强的学习者。

| 系统 | 剧情含义 |
| --- | --- |
| 计算 | AI 能把普通棋盘上的希望一点点算干净 |
| 自我训练 | 它不断迭代版本，越过人类经验的边界 |
| 快速学习 | 终局第一局后，AI 没有听见棋魂，却学会了棋魂的形状 |
| 棋魂 | 科王在旧规则走到尽头后创造出的新规则，也是后续真实棋局的核心机制 |
