## ✨ 当前版本

当前线上版本是 **剧情主线版**：先完整呈现《科王象棋》的故事，并在关键事件中接入真实棋局，让玩家从“八冠王”一路走到棋魂觉醒。

| 内容 | 说明 |
| --- | --- |
| 主角 | 你，象棋界年少成名的八冠王 |
| 对手 | 横空出世的 AI，靠计算、训练和快速学习压过旧棋盘 |
| 主线 | 人机大战惨败 → 信念崩塌 → 棋魂觉醒 → 创造新规则 → 终局前两胜 |
| 玩法状态 | 剧情事件已接入真实棋盘；棋盘内的选子、提示、AI、结算沿用原游戏实现 |
| 进度 | 浏览器本地保存 |

## 📖 剧情结构

| 篇章 | 核心事件 |
| --- | --- |
| 序章 | 你少年封王，八冠加身，成为旧棋盘里最耀眼的人 |
| 第一幕 | AI 横空出世，人类棋手接连倒下 |
| 第二幕 | 你承载人类希望出战十番棋，却被彻底击碎 |
| 第三幕 | 你怀疑的不只是自己，而是整套旧规则 |
| 第四幕 | 雨夜重开棋盒，车魂初醒 |
| 第五幕 | 车、马、炮、兵、仕、相依次觉醒，每一枚棋子都打开一种新规则 |
| 第六幕 | 王魂与组合技出现，你不再只是解锁能力，而是在创造一套棋 |
| 终幕 | 三局两胜：前两局必须连胜，趁 AI 还没完全掌握棋魂结束比赛 |

## 🧠 AI 与棋魂设定

故事里的 AI 不是传统反派，而是旧规则里最强的学习者。

| 系统 | 剧情含义 |
| --- | --- |
| 计算 | AI 能把普通棋盘上的希望一点点算干净 |
| 自我训练 | 它不断迭代版本，越过人类经验的边界 |
| 快速学习 | 终局第一局后，AI 没有听见棋魂，却开始学会棋魂的形状 |
| 棋魂 | 你在旧规则走到尽头后创造出的新规则，也是后续真实棋局的核心机制 |
